# Acme Platform (monorepo)
- `frontend/` React + TypeScript SPA (operations dashboard, login, integrations, workflow editor, record review, assistant)
- `backend/` FastAPI service
- `infra/terraform/` GCP infrastructure
- `k8s/` Kubernetes manifests
- `sql/` reporting queries
- `iam/` IAM policies
- `jobs/` Spark batch jobs
