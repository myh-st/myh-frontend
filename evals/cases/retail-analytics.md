# EVAL-05 — Retail Performance Analytics

## Prompt

Design and implement a responsive retail-performance analytics workspace using the existing reporting APIs.

Users need:
- revenue, margin, conversion, and returns trends;
- comparison by region/store/category;
- date and segment filters;
- anomaly callouts;
- drill-down from aggregate trend to store/category detail;
- export of the currently filtered view.

## Transfer expectations

Use an **analytics-first** structure with charts and comparisons that answer decisions. Avoid turning every metric into a separate card. Filters must clearly affect the scoped results. Small screens should prioritize the key trend and move comparison detail behind deliberate drill-down.
